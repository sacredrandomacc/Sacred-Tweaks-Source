# Sacred Tweaks UI reference image prompt

Use this prompt to generate a visual reference for the desktop app and in-game companion. Treat it as a visual exploration, not a source of product behavior or implementation details.

```text
Create a polished UI design reference sheet for “Sacred Tweaks,” a Windows desktop companion for Fortnite players. Show four distinct 16:10 desktop application screens side by side in a clean product-design presentation: Home, Macros, Windows, and Appearance. These are four screens of the same coherent app, not four separate products. Use crisp, realistic desktop UI, precise typography, aligned grids, restrained shadows, clear spacing, and legible short labels. Do not include Fortnite gameplay, copyrighted characters, weapons, logos, or game footage.

Visual direction: calm, premium, practical, focused, and readable during play. Use a charcoal base surface (#111318), slightly lighter charcoal panels, warm white text (#F2F0EA), cool-gray secondary text, and a restrained violet accent (#9A82F7). Include subtle borders and small violet highlights. Keep all colors and controls visually believable as adjustable appearance settings. Avoid neon overload, gradients behind text, tiny low-contrast labels, glassmorphism, and decorative clutter.

Screen 1 — Home: a compact overview with a clear “Ready” status, signed-in account and tier, Fortnite detected/ready indicator, a large “Open main app” action, and small cards linking to macros, Windows tools, and appearance. Keep the overlay focused on practical controls. Do not show performance graphs, measurements, backups, or restore controls here.

Screen 2 — Macros: a clean list of saved macro profiles with name, macro type, and last-saved time. Include a selected profile’s readable keybind and timing editor, a “Save profile” action, and an “Open Macro Studio” action. Saving does not activate a macro. Do not show an enable/execute control or imply that gameplay inputs are running.

Screen 3 — Windows: simple shortcut cards for supported Windows settings such as Display, Game Mode, and Filter Keys. Each card has a plain description and a clear “Open Windows settings” action. Avoid fake toggles for controls the app cannot directly manage.

Screen 4 — Appearance: show Wide as the fixed overlay size, screen position (Center, Left, Right), overlay opacity, accent color, decorative animations On/Off, and a “Reset recommended palette” action. Show a live preview card using the current colors. Make these settings easy to recognize and adjust.

Use a consistent sidebar or compact top navigation with Home, Macros, Windows, and Appearance. Include clear selected states, accessible contrast, keyboard focus indication where visible, and a small unobtrusive close/minimize affordance. Make the four screens feel implementable with standard Windows desktop UI components. Add no extra screens, fake telemetry, automatic optimizers, or unlabeled controls. Render all interface text correctly and avoid garbled pseudo-text.
```
